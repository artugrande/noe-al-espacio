# Gameplay depth (v2.1)

## Goal
More challenge and replayability without changing the core loop (dodge → collect → dock).

## Systems
1. **Combo** — consecutive pickups raise a score multiplier (cap x4). Resets on any junk hit (even if shield saves you).
2. **Near-miss** — junk that passes close without colliding awards points and can extend combo feel.
3. **Formations** — occasional wall-with-gap, V, and diagonal junk patterns.
4. **Junk variants** — normal / heavy (bigger hitbox) / splitter (shield break spawns 2 small pieces).
5. **Turbulence** — short windows of lateral shake on the rocket.
6. **Secondary objective** — collect N mates in a run for a bonus + achievement.

## Non-goals
No new screens, no difficulty select, no multiplayer.
